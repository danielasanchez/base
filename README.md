## 🛠️ Instalación y ejecución para Vite

```bash
# Entrar a la carpeta ejemploVite
cd ejemploVite

# Instalar dependencias
npm install

# Ejecutar el servidor
npm run dev
```

## 🛠️ Instalación y ejecución para CRA

```bash
# Entrar a la carpeta ejemplocra
cd ejemplocra

# Instalar dependencias
npm install

# Ejecutar el servidor
npm start
```
